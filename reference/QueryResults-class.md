# A Redland QueryResults object is used to inspect query results from a Query object.

The QueryResults object contains the RDF statements that were returned
from a query on an RDF model.

## Slots

- `librdf_query_results`:

  A redland query object

## Methods

- [`QueryResults-initialize`](https://docs.ropensci.org/redland/reference/QueryResults-initialize.md):
  Initialize a QueryResults object.
  [`freeQueryResults`](https://docs.ropensci.org/redland/reference/freeQueryResults.md):
  Free memory used by a librdf query result.
