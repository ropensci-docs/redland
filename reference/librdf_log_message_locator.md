# Retrieve locator of log entry.

Retrieve locator of log entry.

## Usage

``` r
librdf_log_message_locator ( message )
```

## Arguments

- message:

  log message ("\_p_librdf_log_message")

## Value

\_p_raptor_locator

## References

<https://librdf.org/docs/>

## See also

Redland RDF C libraries. For more information about Redland RDF, view
