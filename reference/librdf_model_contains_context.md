# Check for a context in the model.

Check for a context in the model.

## Usage

``` r
librdf_model_contains_context ( model,
  context,
  .copy )
```

## Arguments

- model:

  the model object ("\_p_librdf_model_s")

- context:

  the contest ("\_p_librdf_node_s")

- .copy:

  NA

## Value

integer

## References

<https://librdf.org/docs/>

## See also

This R function is a wrapper function that directly calls the the
Redland RDF C libraries. For more information about Redland RDF, view
the online documentation indicated in the 'References' section.
