# Copy constructor - create a new librdf_node object from an existing librdf_node object.

Copy constructor - create a new librdf_node object from an existing
librdf_node object.

## Usage

``` r
librdf_new_node_from_node ( node )
```

## Arguments

- node:

  librdf_node object to copy ("\_p_librdf_node_s")

## Value

\_p_librdf_node_s

## References

<https://librdf.org/docs/>

## See also

This R function is a wrapper function that directly calls the the
Redland RDF C libraries. For more information about Redland RDF, view
the online documentation indicated in the 'References' section.
