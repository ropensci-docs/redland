# Constructor - create a new librdf_uri object from a filename.

Constructor - create a new librdf_uri object from a filename.

## Usage

``` r
librdf_new_uri_from_filename ( world,
  filename )
```

## Arguments

- world:

  Redland librdf_world object ("\_p_librdf_world_s")

- filename:

  filename ("character")

## Value

\_p_librdf_uri_s

## References

<https://librdf.org/docs/>

## See also

This R function is a wrapper function that directly calls the the
Redland RDF C libraries. For more information about Redland RDF, view
the online documentation indicated in the 'References' section.
