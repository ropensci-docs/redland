# Create a new Redland execution environment.

Create a new Redland execution environment.

## Usage

``` r
librdf_new_world (  )
```

## Value

\_p_librdf_world_s

## References

<https://librdf.org/docs/>

Redland RDF C libraries. For more information about Redland RDF, view
