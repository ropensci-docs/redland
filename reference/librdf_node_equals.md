# Compare two librdf_node objects for equality.

Compare two librdf_node objects for equality.

## Usage

``` r
librdf_node_equals ( first_node,
  second_node,
  .copy )
```

## Arguments

- first_node:

  first librdf_node node ("\_p_librdf_node_s")

- second_node:

  second librdf_node node ("\_p_librdf_node_s")

- .copy:

  NA

## Value

integer

## References

<https://librdf.org/docs/>

## See also

This R function is a wrapper function that directly calls the the
Redland RDF C libraries. For more information about Redland RDF, view
the online documentation indicated in the 'References' section.
