# Get a query result as an RDF graph in librdf_stream form

Get a query result as an RDF graph in librdf_stream form

## Usage

``` r
librdf_query_results_as_stream ( query_results )
```

## Arguments

- query_results:

  librdf_query_results query_results ("\_p_librdf_query_results")

## Value

\_p_librdf_stream_s

## References

<https://librdf.org/docs/>

## See also

This R function is a wrapper function that directly calls the the
Redland RDF C libraries. For more information about Redland RDF, view
the online documentation indicated in the 'References' section.
