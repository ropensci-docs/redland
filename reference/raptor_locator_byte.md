# Get the locator byte offset from locator.

Get the locator byte offset from locator

## Usage

``` r
raptor_locator_byte ( locator, .copy )
```

## Arguments

- locator:

  raptor locator ("\_p_raptor_locator")

- .copy:

  logical

## Value

character
