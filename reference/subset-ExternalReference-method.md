# Assign values in a list of ExternalReferences

Assign values in a list of ExternalReferences

## Usage

``` r
# S4 method for class 'ExternalReference'
x[i, j, ...] <- value
```

## Arguments

- x:

  a list of ExternalReferences

- i:

  row subscript

- j:

  column subscript

- ...:

  additional arguments

- value:

  a value to assign
